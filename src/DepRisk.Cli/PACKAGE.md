# DepRisk

Reachability-aware, uncertainty-driven dependency vulnerability triage and verified remediation planning, from your terminal.

> **Status: pre-alpha.** This release reserves the package name and ships the CLI skeleton (`--version`, `doctor`). Analysis features are on the roadmap.

```bash
dotnet tool install -g DepRisk.Cli
deprisk --version
deprisk doctor
```
